Privacy Policy

Effective 21 November 2026. Versão em português.

YT Empire Painel ("the app") is a private, read-only analytics tool used only by the owner of the YouTube channels it reads. This policy explains which data it accesses and what happens to it.

Data the app accesses

With the owner's Google authorization, the app reads, for the owner's own channels only:

  • channel and video metadata (titles, publication dates, durations);
  • video and channel statistics (views, likes, comments, subscribers);
  • YouTube Analytics reports (for example daily views, watch time, audience retention and, when the owner chooses to grant it, estimated revenue).

The app requests only read-only scopes (youtube.readonly, yt-analytics.readonly and, optionally, yt-analytics-monetary.readonly). It does not read e-mail, contacts, Google Drive or any other Google data, and it does not access other people's channels.

How the data is used

Only to show the owner how his own channels perform over time. The data is not used for advertising, is not sold, and is not shared with third parties.

Storage and security

The data is stored in the owner's own private storage (a private server and a private Backblaze B2 storage bucket). OAuth tokens are kept in a private secrets manager and are never published. Access is limited to the owner.

Retention and deletion

The owner keeps the historical statistics of his own channels for as long as he uses the app. The app checks at least every 30 days that its authorization is still valid. When the authorization is revoked, the app stops collecting. The owner can delete the stored data at any time.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.

Google API Services

The app uses YouTube API Services and complies with the YouTube API Services Terms of Service. See also the YouTube Terms of Service and the Google Privacy Policy. The app's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes

Changes to this policy are published on this page with a new effective date.

Política de Privacidade (português)

O YT Empire Painel é uma ferramenta interna, pessoal e somente leitura, usada apenas pelo dono dos canais do YouTube que ela lê.

  • O que acessa: com a autorização do dono, metadados e estatísticas dos canais dele (títulos, datas, views, likes, comentários, inscritos) e relatórios do YouTube Analytics (views por dia, tempo de exibição, retenção e, se o dono autorizar, receita estimada). Escopos só de leitura: youtube.readonly, yt-analytics.readonly e, opcionalmente, yt-analytics-monetary.readonly.
  • Uso: só para o dono acompanhar o desempenho dos próprios canais. Nada é vendido, compartilhado ou usado para publicidade.
  • Armazenamento: no armazenamento próprio do dono (servidor privado e bucket privado no Backblaze B2). Tokens OAuth ficam num gerenciador de segredos privado.
  • Retenção: o histórico dos próprios canais é mantido enquanto o dono usar o app. A autorização é conferida pelo menos a cada 30 dias, e a coleta para se ela for revogada. O dono pode apagar os dados quando quiser.
  • Revogar acesso: myaccount.google.com/permissions.
  • O app usa os YouTube API Services e segue os Termos de Serviço do YouTube e a Política de Privacidade do Google.
